Print the numbers from 1 to `n`, one per line, with three substitutions:

- multiples of 3 print `Fizz` instead of the number,
- multiples of 5 print `Buzz`,
- multiples of both print `FizzBuzz`.

## Input

A single integer `n` (1 ≤ n ≤ 10⁵).

## Output

`n` lines, as described.

## Example

```
5
```

prints

```
1
2
Fizz
4
Buzz
```

A good first solution in a language you're learning. The test that catches people is 15.
